# Agent rules

Rules for AI agents (and humans) working in this repo.

## Code comments

- **No comments that restate code**: comments explain _why_, not
  _what_. If a comment describes app behavior, keybinds, or history
  instead of the reasoning behind the code it sits on, it does not
  belong in the code.
- **NEVER use emdashes or endashes**: rewrite the sentence or use
  different punctuation. Ranges use a regular hyphen. This applies to
  comments, docs, commit messages, and UI copy alike.
